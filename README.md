# Our First Anniversary

A scroll-driven anniversary page: a sunflower and tulip bouquet zooms in, you climb down the stem past the photos, then open the envelope for the letter.

It is plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser, or publish the folder with GitHub Pages.

## Editing

- Photos live in `photos/`. The order and sizes are set in the `PHOTOS` list near the top of the script in `index.html`.
- The cover photo is `photos/cover.jpg`, and the florist tag text is in the `.cover` block.
- The letter text is inside `<article class="paper">`.
